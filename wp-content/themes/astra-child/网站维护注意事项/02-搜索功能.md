# 搜索功能 — 完整说明

## 涉及文件

- **`functions.php`** — 搜索表单 HTML（第 34 行附近）+ 后端拦截逻辑（template_redirect 钩子）
- **`search.php`** — 搜索结果页面模板

## 一、前端搜索表单（functions.php）

```html
<form class="top-search" action="/" method="get">
    <input type="text" name="s" placeholder="搜索档案、事件、人物..."
           required pattern=".*[a-zA-Z0-9\u4e00-\u9fff].*"
           title="请至少输入一个字母、数字或中文">
    <button type="submit">搜索</button>
</form>
```

### 校验规则

| 层级 | 机制 | 拦截内容 |
|------|------|----------|
| 前端 `required` | 浏览器原生 | 空输入 |
| 前端 `pattern` | 正则 | 纯空格、纯符号（如 `@#$%`） |
| 后端 `template_redirect` | PHP `preg_match` | 绕过前端的非法请求 |

---

## 二、后端拦截逻辑（template_redirect 钩子，约 functions.php 280 行）

```php
add_action('template_redirect', function () {
    if (is_search() && isset($_GET['s'])) {
        $s = trim($_GET['s']);
        // 1. 空搜索 → 回首页
        if ($s === '') { wp_redirect(home_url('/')); exit; }
        // 2. 彩蛋：搜索 "CRRG-917" → 跳转管理面板
        if (strtolower($s) === 'crrg-917') { wp_redirect(home_url('/admin/')); exit; }
        // 3. 纯符号 → 回首页
        if (!preg_match('/[a-zA-Z0-9\x{4e00}-\x{9fff}]/u', $s)) { wp_redirect(home_url('/')); exit; }
    }
    // 4. 404 /register → 跳转注册页
    if (is_404() && $_SERVER['REQUEST_URI'] === '/register') {
        wp_redirect('/wp-login.php?action=register'); exit;
    }
});
```

## 三、搜索结果页（search.php）

### 搜索范围

默认同时搜索：
- **`post`**（文章，归档新闻）
- **`topic`**（论坛话题）

> 不搜索 `page`（页面）

### Tab 切换

- **全部** — 文章 + 论坛话题混合
- **文章** — 仅 post
- **论坛话题** — 仅 topic

通过 URL 参数 `?s=关键词&type=post` / `?s=关键词&type=topic` 切换。

## 四、已知问题 & 注意事项（2026-09 更新）

1. **文章数量**：`post` 类型现有 20 篇已发布文章（2026-09-01 清理 28 篇"x"占位文章后），搜索可正常命中。
2. **论坛话题已清理**：2026-08-28 清理了约 220 个格式化机器人帖子（时间词模板、档案办案腔、监测周报类），现存约 35 个话题，以生活化闲聊为主。所以搜到论坛话题变少、且大多是口语标题，是清理后的正常状态。
3. **`pattern` 属性限制**：HTML5 `pattern` 仅对表单提交生效，直接访问 URL（如 `/?s=@#$`）只能靠后端拦截。
4. **修改搜索行为**：需要改三处——前端 `pattern`、后端 `preg_match`、`search.php` 模板。
